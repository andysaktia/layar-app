Pengaturan & mode

Pilih sesuai kebutuhanmu. Key tersimpan hanya di browser ini, dan ganti mode tidak menghapus daftar tontonanmu (kecuali judul contoh).

Sekarang Mode Contoh. Isi key OMDb atau TMDB untuk beralih ke data asli.

Cepat: tanpa daftar akun

  • Drama/serial lewat TVmaze, langsung jalan tanpa key.
  • Film lewat OMDb: key gratis dari email, tanpa formulir panjang.
  • Jelajah acak, tanpa filter genre, Terbaru, dan halaman.

Lengkap: butuh key TMDB (±5 menit)

  • Jelajah dengan Terbaru, Populer, Rating, genre, dan nomor halaman.
  • Sinopsis, genre, dan pemeran berbahasa Indonesia.
  • Gratis untuk pemakaian non-komersial. Daftar di themoviedb.org → Settings → API.

Kamu sedang di Mode Contoh

Semua judul yang tampil sekarang adalah data dummy, bukan data film dan drama asli. Cocok untuk melihat-lihat fitur Layar.

Untuk memakai data asli, isi salah satu API key di Pengaturan:

Cepat

  • Key OMDb gratis dari email untuk film. Drama lewat TVmaze, tanpa key.

Lengkap

  • Key TMDB gratis (±5 menit): genre, Terbaru, halaman, sinopsis berbahasa Indonesia.

Judul contoh yang kamu centang akan dihapus otomatis saat key diisi.
